# API Documentation

## Files Overview

### `/highlights/route.ts` (Named Entity Extraction with Caching)

This file exposes a POST API endpoint to extract proper names (Named Proper Nouns) from input text. It uses a natural language processing tagger singleton and caches results with an LRU cache to optimize repeated requests.

- Uses `preprocessText` to clean input text.
- Tags text with the `tagger` singleton.
- Groups tagged words by lowercase token and filters groups where all tags are "NNP" (proper names).
- Caches results associated with the full input text.
- Exposes a testing-only resetCache function to inject or reset the cache.

---

### `/names/route.ts` (Regex Matching)

This route provides a POST endpoint for matching text against a set of regex rules:

- Reads JSON from request with `text` to scan and a `chars` configuration.
- Uses a `Rules` utility that configures regex rules dynamically.
- Finds all matches of the rules in the text.
- Responds with an array of matches indicating start index and length.

---

### `tagger.singleton.ts`

Exports a singleton instance of a tagger generated by the utility `generateTagger`. It ensures a single shared tagger instance is used across the application for consistency and performance.

---

### Data Files

- `names.json`: Contains an array of personal names, often used for validation, tagging, or suggestions.
- `countries.json`: Contains an array of country names and region names used throughout the application for geographic-related functions or dropdown selections.
